Ein Code ist die Eintrittskarte für ein neues Konto. Der Gast meldet sich mit Discord an und trägt den Code einmal ein – danach gehören Discord-Konto und Konto hier zusammen.

Ein Code, der schon eingelöst wurde, lässt sich nicht wiederverwenden. Zurückziehen wirkt nur auf noch offene Codes; bereits angelegte Konten bleiben bestehen.
